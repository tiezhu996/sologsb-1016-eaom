# 声场 · 广播剧台词与音效提示编辑器

一个离线优先的广播剧制作台，使用 Vue 3、Vite、TypeScript 和 Naive UI 从零实现。项目按场次管理角色台词、情绪、语速、音效素材与转场提示；提示顺序改变后自动重算时长，并检查角色撞场、音效引用缺失和场次超时。

## 双窗口协作（导演 / 编剧）

打开页面后先选择当前窗口身份：**导演窗口**或**编剧窗口**（在另一个浏览器窗口/标签页再打开一次，选择另一角色）。两窗口共享同一份本机数据，无需服务器。

- **自动合并**：每次修改都是一条带向量时钟的操作，写入共享操作日志，并通过 `BroadcastChannel` 与 `storage` 事件实时同步到另一窗口。
- **断网可继续**：顶栏可切换“离线”。离线期间的台词、音效、顺序修改进入本机待发队列；恢复连接后整批并入共享日志。
- **绝不旧覆盖新**：冲突按向量时钟判定“并发”。一边已经看过对方修改后的编辑属因果序、直接收敛；只有两边都基于同一旧状态独立改动同一项才算并发，此时**两份内容都保留**，不会让后到的旧窗口覆盖新修改。
- **导演确认区**：冲突卡片左右并排保留双方版本快照与改动摘要，导演可“采用左版/右版”；同一提示项还可“两份都保留”（复制进场次再取舍）。
- **确认记录**：每条编辑记录作者窗口、时间与字段前后值；导演可接受或退回。退回是携带修改前快照的确定性补偿操作，两窗口一致回放。
- **冻结与还原可溯源**：冻结版本保存不可变快照，并列出构成该制作稿的每条编辑来源（仅含真正进入成品的编辑，已退回/未采用的不计）。冻结版本与已接受的确认记录都可还原到各自来源。
- **未处理完冲突不得导出**：只要存在未决冲突，“冻结并导出”按钮禁用，并在版本页明确提示。

## 功能

- 场次与提示项增删改、拖动排序（提示项与场次均可拖拽）。
- 根据台词字数、语速、标点和素材时长实时估算总时长。
- 角色撞场、缺失音效引用、场次超限实时检查与一键定位。
- 双窗口操作日志合并、离线队列、向量时钟冲突检测与导演裁决。
- 冻结不可变制作版本（带完整来源清单），生成并下载纯文本制作稿。
- Service Worker 运行时缓存，已打开过的生产页面可离线访问。

## 合并模型

- `src/model.ts`：向量时钟、拓扑排序、按轨道（项目/角色/音效/场次/提示项/顺序）的编辑分叉归约、冲突快照、裁决应用、确认记录与冻结来源派生、时长与检查、制作稿生成。
- `src/sync.ts`：localStorage 共享日志、离线 outbox、BroadcastChannel 传输与窗口在线心跳。
- `src/useStudio.ts`：身份与连接管理、操作发射、本窗口投影（日志 + 离线队列）与全部编辑动作。
- `scripts/merge.test.ts`：合并语义的确定性测试（`npm run test:merge`），覆盖并发冲突、离线重连顺序无关性、旧窗口不得覆盖新修改、裁决/两边都保留、顺序冲突、冻结来源与还原、退回补偿等。


## 技术栈

- Vue 3 + Composition API
- Vite 6
- TypeScript
- Naive UI

## 本地开发

```bash
npm install
npm run dev
```

开发服务器只绑定在本地端口 `5173`，这是开发工具默认端口，不包含任何宿主映射。容器生产环境仅监听 `80`。

## 生产构建

```bash
npm install
npm run build
npm run preview
```

构建结果位于 `dist/`。

## Docker

```bash
docker build -t sologsb-1016 .
docker run --rm -p 10016:80 sologsb-1016
```

容器使用 nginx 监听 `80`，并通过 `try_files` 支持前端路由刷新。宿主端口映射由部署编排负责，源码和 Dockerfile 均未写死宿主端口。

## 数据与离线说明

数据保存在当前浏览器的 `localStorage` 中，不会上传到服务器。Service Worker 缓存生产页面与已访问的静态资源；录音、音效素材本身不在本项目中，制作稿只保存素材引用路径。
