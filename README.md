# 声场 · 广播剧台词与音效提示编辑器

一个离线优先、支持双窗口协同的广播剧制作台，使用 Vue 3、Vite、TypeScript 与 Naive UI 实现。导演与编剧可在两个浏览器窗口中同时编辑同一部广播剧：断网继续修改台词、音效与场次顺序，恢复连接后自动合并。

## 功能

- 场次与提示项增删改、拖动排序（分数排序键，两端并发拖动自动合并）、场次上下移动。
- 根据台词字数、语速、标点和素材时长实时估算总时长。
- 角色撞场、缺失音效引用、场次超时实时检查与一键定位。
- **双端离线协同（事件溯源）**
  - 每次编辑是一条带 HLC 逻辑时钟、来源身份和向量时钟的批次事件，只追加、不覆盖；`BroadcastChannel` 在同机窗口间实时增量同步，另支持导出/导入 JSON 同步文件。
  - 断网期间两端可独立修改；恢复后按 happens-before 因果关系做三向归约。
  - 改不同字段自动合并；**同一提示项两边都改过时保留两份内容**，进入导演确认区逐条选择 A 侧 / B 侧，或批量裁决。
  - 一方删场次、另一方离线改场中提示项时，选择保留方会自动恢复被删场次。
  - 退回采用「归约时跳过该批次」而非旧状态回写，因此不会拿旧窗口覆盖并发的新修改；同窗口离线产生的迟到后代批次保留为待确认，并标记其祖先已退回。
- **导演确认流**：每条修改带作者与窗口来源，导演可接受 / 退回 / 全部接受；退回较早记录会级联其同窗口因果上的后续未决批次，其他窗口并发修改不受影响。
- **溯源与还原**：每个场次 / 提示项记录最后修改来源（作者、窗口、时间）；冻结版本是不可变快照，已接受的确认记录和冻结版本都可以一键还原到各自来源。
- **导出闸门**：冲突没有全部处理完时不能冻结导出制作稿；未接受的普通修改只作提示。
- 撤销（生成本地逆向批次，同样进入确认流）、自动保存到 `localStorage`，刷新或离线不丢任何事件。
- Service Worker 运行时缓存，已打开过的生产页面可离线访问。

## 模拟两个窗口

浏览器中打开两个标签页后，用顶栏「切换导演 / 切换编剧」给两个窗口分配身份。同机标签页通过 `BroadcastChannel` 实时合并；也可以在两个窗口分别「导出同步文件」→ 另一窗口「导入同步文件」来模拟断网恢复。所有数据都保存在各自窗口的 `localStorage`，不上传服务器。

## 技术栈

- Vue 3 + Composition API
- Vite 6
- TypeScript
- Naive UI
- 自研协同内核：HLC + 向量时钟 + 只追加事件日志 + 因果拓扑归约 + 分数排序键

## 本地开发

```bash
npm install
npm run dev
```

开发服务器只绑定在本地端口 `5173`，这是开发工具默认端口，不包含任何宿主映射。容器生产环境仅监听 `80`。

## 合并核心测试

```bash
npm run test:sync
```

覆盖：离线不同字段自动合并、同字段双份保留与裁决、删场次 vs 改台词的跨实体冲突、退回不覆盖并发新修改、离线迟到批次保护、并发拖动排序、逆向撤销、冻结快照不可变与记录还原、单侧退回自动关闭冲突。

## 生产构建

```bash
npm install
npm run build
npm run preview
```

构建结果位于 `dist/`。

## Docker

```bash
docker build -t sologsb-1016 .
docker run --rm -p 10016:80 sologsb-1016
```

容器使用 nginx 监听 `80`，并通过 `try_files` 支持前端路由刷新。宿主端口映射由部署编排负责，源码和 Dockerfile 均未写死宿主端口。

## 数据与离线说明

协同事件日志保存在当前浏览器的 `localStorage`（`sologsb-1016-studio-v2`），不会上传到服务器；旧版 v1 单窗口草稿会在首次打开时自动迁移。Service Worker 缓存生产页面与已访问的静态资源；录音、音效素材本身不在本项目中，制作稿只保存素材引用路径。
